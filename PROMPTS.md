# PROMPTS

The 11 prompts used to build this project, one per file under [`prompts/`](prompts/).

1. [Kinematics PPTX](prompts/01-kinematics-pptx.md) — 10-slide "Intro to 1D Kinematics" deck (`generate_kinematics_pptx.py`)
2. [Projectile Motion XLSX](prompts/02-projectile-motion-xlsx.md) — no-drag trajectory workbook (`generate_projectile_motion_xlsx.py`)
3. [Projectile Drag XLSX](prompts/03-projectile-drag-xlsx.md) — ideal vs. drag comparison workbook (`generate_projectile_drag_xlsx.py`)
4. [Projectile Report DOCX](prompts/04-projectile-report-docx.md) — Word report with embedded trajectory plot (`generate_projectile_report_docx.py`)
5. [Projectile Paper PDF](prompts/05-projectile-paper-pdf.md) — LaTeX-compiled academic paper (`generate_projectile_paper.py`)
6. [Interactive Web App](prompts/06-interactive-web-app.md) — single-file Canvas/JS simulator (`index.html`)
7. [Streamlit Dashboard](prompts/07-streamlit-dashboard.md) — Plotly-based analysis dashboard (`app.py`)
8. [Docker Containerization](prompts/08-docker-containerization.md) — `Dockerfile`, `docker-compose.yml`, `.dockerignore`
9. [GitHub Actions CI](prompts/09-github-actions-ci.md) — lint/build/publish workflow (`.github/workflows/ci.yml`)
10. [PyTest Suite](prompts/10-pytest-suite.md) — physics unit tests (`tests/test_physics.py`, `physics.py`)
11. [Coverage Reporting](prompts/11-coverage-reporting.md) — `pytest-cov` config, HTML/XML reports, CI coverage gate
